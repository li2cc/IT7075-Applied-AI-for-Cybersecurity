Getting Started with the Mini Project

Module 04: Retrieval-Augmented Generation (RAG) · Three steps: get the code, install the packages, run the notebook.

1. Get the code

Pick where you will work. You can switch later: the notebook is the same everywhere.

Google Colab

  1. Go to colab.research.google.com, choose File → New notebook, and run this once. It copies the course repository into your Google Drive.
from google.colab import drive
drive.mount("/content/drive")
!git clone https://github.com/li2cc/IT7075-Applied-AI-for-Cybersecurity.git /content/drive/MyDrive/IT7075
  1. In Google Drive, go to My Drive → IT7075 → 04_RAG → assignments → project, right-click MiniProject_RAG_Starter.ipynb, and choose Open with → Google Colaboratory.
  2. Add a code cell at the very top of the notebook, paste this in, and run it. Do this every time you open the notebook: Colab starts in /content, not in the notebook's folder, and without this cell the notebook cannot find its files.
from google.colab import drive
drive.mount("/content/drive")
%cd /content/drive/MyDrive/IT7075/04_RAG/assignments/project

Jetstream2 or your own computer

In a terminal (on Jetstream2, a terminal on the VM desktop; see the VM Access Guide), run:

git clone https://github.com/li2cc/IT7075-Applied-AI-for-Cybersecurity.git IT7075
cd IT7075
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install jupyterlab
jupyter lab

In JupyterLab, open 04_RAG/assignments/project/MiniProject_RAG_Starter.ipynb. Next time, just cd IT7075, activate .venv, and run jupyter lab. On your own computer you need Python 3.10–3.12 and Git. On Windows, type python instead of python3.

2. Install the packages

Find this line at the top of the notebook's first code cell:

# If needed:  !pip install -q sentence-transformers chromadb pandas matplotlib openai

Delete # If needed: so the line starts with !pip, then run the cell. This installs every package the notebook needs.

  • Colab: run it again in every new session. Colab forgets installed packages when it shuts down.
  • JupyterLab or VS Code: change !pip to %pip, so the packages go into the notebook's own Python. You only need to run it once.

3. Run the notebook

Run the cells from top to bottom. Part 1 should print ssrf.txt -> 11 chunks, cybersecurity_kb.md -> 11 chunks, 22 total. If it does, you are set up. No API key or GPU is needed: without a key, the generate step prints an offline answer.

If something goes wrong

You seeDo this
ModuleNotFoundError: No module named 'chromadb'Run the install line from step 2. On Colab, run it again after every restart. In JupyterLab or VS Code, make sure it says %pip, not !pip.
FileNotFoundError: ... ssrf.txtThe notebook is not running from its own folder. On Colab, run the %cd cell from step 1. Elsewhere, open the notebook inside your cloned IT7075 folder, not a downloaded copy.
NameError: name '____' is not definedNot a setup problem. A TODO blank is still waiting for your code.
externally-managed-environment when you run pipActivate the .venv first (source .venv/bin/activate).
ensurepip is not available when creating .venvOn Jetstream2 or Ubuntu, run sudo apt install -y python3-venv, then create the .venv again.
